# verso application shell

Mode: Operate. This extends the existing reading workspace, using the user-confirmed composition. No alternative visual world is introduced.

## Direction
A quiet, compact workbench: persistent navigation, a legible conversation, visible input/output attachments and a docked reading pane. Work and provenance lead, chrome recedes.

## Visual authority
`../Brand/mitwerk-light-dark-design-system.html`, specifically the `#mitwerk-overview` palette (not the enclosing demo site's generic theme). Werk Blue #1D4AB9, Mit Sky #E4ECFF, Workshop Text #191A1B, Panel White #FAFAFA, Steel #65676C, Rail #E7E7E7. Operation colors remain semantic. Keep Neurial Grotesk from the existing repository. Fine borders, 4–8px corners, 4px spacing units, sparse shadows for floating overlays only.

## First viewport and behavior
Sidebar 220px. Task header and asset cards occupy the upper work surface. Conversation has generous reading space and a bottom composer. Opening an attachment docks a reader without erasing the draft. Expanded reader increases the available work area. At narrow widths navigation collapses and the reader becomes a full workspace overlay.

## Quality bar
An intelligible project → task → attachment → preview/history path. Preserve version-tree behavior. Native keyboard controls, visible focus, no horizontal page overflow. Treat all demo messages, participants and outputs as sample content. Never imply a real AI request or colleague message was sent.
